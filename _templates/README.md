# `_templates/` — Markdown Templates for the Second Brain

Copy these templates when creating new documents in the Second Brain:

| Template | Target Folder | When to Use |
|---|---|---|
| **[`inbox-note.md`](inbox-note.md)** | [`inbox/`](../inbox/README.md) | Quick brain-dump in the browser editor (no required frontmatter). *(Tip: commenting `Learned: ...` on a board issue creates `inbox/issue-<N>.md` automatically!)* |
| **[`page.md`](page.md)** | [`knowledge/<domain>/`](../knowledge/README.md) or [`standards/`](../standards/README.md) | Curated operational guide, runbook, or engineering standard (`_meta/schema.yaml`). |
| **[`adr.md`](adr.md)** | [`decisions/`](../decisions/README.md) | Architecture Decision Record linked to a `[Decision]` issue card via `related_cards`. |
